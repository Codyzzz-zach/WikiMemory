# ADR-0003：采用加权证据流语义与可闭合的收敛阶段

- 状态：Accepted
- 日期：2026-08-24
- 决策者：产品负责人
- 关联基线：`docs/specs/wikimemory-convergence-baseline-v1.md`

## Context

WikiMemory 已经完成 Evidence Kernel、Agent Runtime 和以长期问题组织 WikiModule 的主要机制，但此前文档仍容易把 `CURRENT`、`DISPUTED`、`SUPERSEDED` 写成确定的终局状态，并把“最新 ACTIVE”近似为当前真相。

I3-Sim 进一步证明：当前系统能够稳定地产生可追溯模块，但真实冻结材料没有充分触发争议/取代语义，条件表达和跨版本关系也仍有缺口。继续在同一个 Gate 内追加补丁，会让验收对象和目标同时移动，无法判断阶段何时完成。

产品负责人明确提出：争议和取代本身是带权重的信息流动，类似搜索过程中分支价值与注意力的变化；它不能承诺百分之百确定。项目目标也不是尽快交付 Alpha，而是让每一阶段能够落盘、闭合，并把新发现与当前目标隔离。

## Decision

1. WikiMemory 的核心产品语义改为“围绕长期问题的加权证据拓扑”。
2. `CURRENT` 解释为给定知识版本、适用范围和任务语境下当前领先/证据支持更强的分支，而不是客观真理。
3. 争议、条件、取代、未决和历史分支被视为信息权重、适用范围、可见性和优先级的变化；所有变化必须能回到证据和关系依据。
4. 新材料获得当前性和重新检查的先验，但不自动获得高于旧材料的权威，也不得静默删除旧分支。
5. 权重首先以可解释向量、序位和理由表达；当前阶段不承诺统一概率、MCTS 实现或单一综合分数。
6. 产品知识边界继续限定为人类主动选择的材料。Agent 运行轨迹、日志和任务结果只用于评测，除非被明确选择为新材料。
7. 后续研发使用 `C0 → C1 → C2 → C3` 收敛路线。每个阶段在执行前冻结主变量、输入切片、接受向量、预算、非目标、停止条件和闭合产物。
8. 新发现默认进入 Discovery Backlog，不自动改变当前阶段。`NO-GO`、`STOP` 和 `NARROW` 都是合法闭合结果。
9. 当前接受 C0 基线；I3-Sim 保持 `NO-GO`，不通过追加同轮补丁改写结论。下一步仅允许起草和评审 C1 合同，尚未授权 C1 实现。

## Consequences

### Positive

- 产品不再用二值状态承诺超出证据的确定性；
- 确定性机制与模型判断有明确边界，模型成本可以集中到真实歧义；
- 负实验可以形成阶段资产，不再迫使目标后移；
- 文档、代码和评测可以明确区分“机制已存在”和“产品语义已证明”。

### Costs and risks

- 现有 `ACTIVE/SUPERSEDED` 等 schema 名称短期仍存在，需要避免把存储状态直接暴露成产品真理；
- 加权语义可能增加展示和评审复杂度，必须通过 C1 缩小最小表达；
- 多维权重存在被伪精确化的风险，因此 C1 必须优先保留解释而不是追求一个漂亮分数；
- C3 的真实长期价值会更晚得到答案，但阶段证据会更清晰。

## Alternatives considered

### 继续以最新 ACTIVE 作为唯一当前答案

拒绝。它把时间顺序替代了权威、范围和关系判断，会抹平仍然有效的旧分支。

### 为每个 Claim 立即计算统一概率

拒绝。现阶段没有足够校准数据，单一概率会制造伪确定性并隐藏成本/适用性取舍。

### 把 Agent 每次运行自动纳入长期记忆

拒绝。它偏离“人类选择知识材料进入编译”的产品场景，并引入大量未经授权的噪声。

### 立即以 Alpha/Pilot 交付作为收敛目标

拒绝。当前需要解决的是阶段闭合和语义缺口，不是用发布日期代替产品学习。

### 继续修补 I3-Sim 直到通过

拒绝。I3-Sim 的 `NO-GO` 已经是有效证据；改变机制后应在新的 C1 合同下形成新的可比较实验。

## Supersedes

- ADR-0002 中把后续阶段直接定义为旧 I3 的部分；
- `WGEMemory4LLM-Iteration-Operating-Plan.md` v2.0 中仍然开放的 I3 路线和固定成功阈值；
- 任何把 `CURRENT` 或“最新 ACTIVE”解释为客观真理的非规范性表述。
