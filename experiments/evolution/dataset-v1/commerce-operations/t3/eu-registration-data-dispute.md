# 欧洲站注册资料采集分歧记录

文件编号：HM-EU-2026-10　记录日期：2026-09-22　状态：待裁决

全球增长部提出，欧洲站新用户注册时应强制填写完整账单地址、出生年份和职业类别。增长部认为这些字段有助于计算潜在购买力、减少后续结算步骤并提升营销转化率。其方案要求用户不填写就无法完成注册，并计划把职业类别同步到营销画像系统。

数据隐私合规部反对该方案。合规部认为，在用户尚未下单时，注册所必需的信息只有邮箱、密码和同意记录；账单地址可以在首次购买需要开票或支付验证时再收集，职业类别不应设为必填。合规部要求在完成合法性评估之前禁止上线额外字段，并提出删除增长部已经采集的试验数据。

全球增长部和数据隐私合规部在当前项目中都只有建议和否决权之一，没有文件证明任一部门具有最终裁决权限。欧洲业务负责人尚未签署上线决定，法务也没有发布针对本方案的书面意见。测试环境中同时存在“邮箱即可注册”和“完整资料注册”两套配置。

这份记录的目的只是保存冲突、理由和待办事项。它不能被引用为“已经允许强制收集”，也不能被引用为“公司永久禁止收集账单地址”。最终规则必须来自后续正式决定，并区分注册阶段与实际结算阶段。
