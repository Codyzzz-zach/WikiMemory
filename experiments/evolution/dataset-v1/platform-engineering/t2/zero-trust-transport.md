# Northstar 零信任传输升级通知

文件编号：NS-SEC-2026-09　发布机构：安全架构组　发布日期：2026-06-15　生效日期：2026-07-10

## 明确替代的章节

本通知取代《Northstar API 与服务传输安全标准》（NS-SEC-2026-02）中的“外部接口”和“内部服务通信”两章。自生效日起，外部 API 不再允许仅使用 TLS 1.2，内部受管网络也不再享有明文 HTTP 的通用许可。原文件的服务身份令牌九十天轮换、Argon2id 密码存储、日志脱敏和临时降级审批要求继续有效，因为这些独立控制不在本次替代范围内。

## 新传输要求

所有外部 API 必须使用 TLS 1.3。仍只支持 TLS 1.2 的合作伙伴需要在生效日前完成升级；未完成时网关应拒绝连接，而不是自动降级。所有生产微服务之间的调用必须启用 mTLS，调用双方都要验证由公司服务身份系统签发的短期证书。跨区域、同区域和同一集群内的调用采用相同要求。

mTLS 证书由平台自动轮换，默认有效期二十四小时。证书轮换异常时，服务可以继续使用尚未过期的当前证书，但不得切换为明文。开发机到测试环境的调试流量不属于生产微服务通信，仍需通过受控代理接入。

## 例外管理

安全架构组可以针对明确的兼容性故障批准最长二十四小时的临时例外，批准文件必须列出目标服务、补偿控制和结束时间。性能压力、营销活动或流量增长本身不是自动例外。任何部门都不能仅凭内部备忘录长期关闭 mTLS。
