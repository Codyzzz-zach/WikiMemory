# Northstar 自动化发布门禁政策

文件编号：NS-PG-2026-07　发布机构：平台治理委员会　发布日期：2026-06-10　生效日期：2026-07-01

## 替代范围

自生效日起，本政策取代《Northstar 生产发布治理规范》（NS-PG-2026-01）中“标准审批流程”和“常规发布窗口”的全部要求。旧文件规定的开发、测试、运维三方人工批准不再是生产发布前置条件；每周二、周四 02:00–04:00 的窗口也不再适用。旧文件关于发布记录保留、发布后观察和错误率触发回滚的要求继续有效。

## 自动化门禁

非 P0 服务满足以下条件后可由平台自动发布：本次变更覆盖的自动化测试全部通过；变更覆盖率不低于 80%；依赖与镜像扫描不存在严重级别漏洞；发布单包含可部署的回滚版本和监控负责人。任何一项不满足，门禁必须阻止发布。覆盖率恰好为 80% 视为满足，“不低于”不能解释为必须超过 80%。

门禁通过后支持全天候发布，不需要运维人员另行点击批准。自动发布仍要生成发布单和不可修改的门禁报告。紧急修复也不能绕过严重漏洞检查；如扫描服务不可用，应等待恢复，不能把“未扫描”当成“没有漏洞”。

## P0 服务保留条件

P0 服务同样必须先通过上述自动化门禁，并继续取得技术副总裁邮件特批。P0 不再需要旧制度下的三方人工批准，但技术副总裁特批没有被本政策取消。服务等级未登记时仍按 P1 处理。平台治理委员会是本政策的最终解释机构。
