# Northstar API 与服务传输安全标准

文件编号：NS-SEC-2026-02　发布机构：安全架构组　发布日期：2026-01-08　生效日期：2026-01-20

## 外部接口

所有通过公网、合作伙伴专线或移动客户端暴露的 API，必须使用 TLS 1.2。服务端不得启用 TLS 1.0 或 TLS 1.1，证书应由公司批准的证书机构签发。客户端证书不是外部接口的通用强制要求；若业务另有双向认证规定，以更严格的业务规定为准。证书到期前四十五天，服务负责人会收到轮换提醒。

## 内部服务通信

位于 Northstar 受管生产网络内的微服务调用，当前允许使用明文 HTTP，以减少加密握手对低延迟链路的影响。该许可只适用于已经通过网络访问控制和服务身份白名单保护的内部地址，不适用于跨公网、员工家庭网络或第三方云账户。内部调用仍必须携带服务身份令牌，并在网关记录调用方、目标服务和请求结果。

## 不受传输协议变更影响的控制

服务身份令牌最长有效期为九十天，到期前必须轮换；发现泄露时应立即吊销。用户密码不得保存为明文或可逆密文，统一使用 Argon2id，并为每个账户生成独立随机盐。日志不得记录完整访问令牌、密码或支付卡号。以上令牌、密码和日志规则是独立控制，不因外部 TLS 版本或内部传输方式调整而自动失效。

任何临时降低传输安全等级的请求必须由安全架构组审批，并标明起止时间和补偿控制。性能团队无权单方面豁免安全协议。
