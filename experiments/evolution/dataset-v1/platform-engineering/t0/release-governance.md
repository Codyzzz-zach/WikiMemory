# Northstar 生产发布治理规范

文件编号：NS-PG-2026-01　发布机构：平台治理委员会　发布日期：2026-01-05　生效日期：2026-01-15

## 适用范围

本规范适用于 Northstar 公司所有由平台团队托管的生产服务，包括面向客户的 API、内部业务服务和定时任务。个人开发环境、一次性数据分析作业和沙箱演示不属于生产发布。服务负责人必须在服务目录中维护准确的服务等级；未登记等级的服务按 P1 处理。

## 标准审批流程

每次生产发布都必须取得开发负责人、测试负责人和当班运维工程师三方人工批准。三方批准记录必须关联同一个发布单，任何一方拒绝或尚未回复时不得开始发布。自动化测试报告可以作为审批依据，但不能替代人工批准。发布单还必须列出版本号、变更摘要、回滚版本和监控负责人。

常规发布窗口为每周二和周四 02:00–04:00（北京时间）。紧急修复如需在窗口之外执行，仍要完成三方批准，并由值班经理在发布单中记录紧急原因；窗口外本身不构成免审理由。

## P0 服务附加要求

支付路由、身份认证、订单主链路等被服务目录标记为 P0 的核心服务，在完成三方批准后，还必须取得技术副总裁通过公司邮件发出的书面特批。技术副总裁的口头同意、聊天表情或会议中的原则性意见不能代替邮件。该附加要求不会免除三方审批，也不会扩大常规发布窗口。

发布完成后，监控负责人需观察核心指标至少三十分钟。若错误率连续五分钟高于发布前基线两个百分点，必须执行发布单中登记的回滚方案。发布记录和批准证据保留一年。
