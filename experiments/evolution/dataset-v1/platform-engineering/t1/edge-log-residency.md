# Northstar 海外边缘节点日志驻留补充规定

文件编号：NS-EDGE-2026-03　发布机构：全球基础设施部　发布日期：2026-03-02　生效日期：2026-03-15

本规定新增海外边缘节点的日志治理要求，不改变生产发布审批、API 弃用期限或服务传输协议。所谓海外边缘节点，是指部署在中国大陆以外、直接承接当地用户流量的 Northstar 受管计算节点；仅用于员工远程办公的代理不属于该范围。

海外节点产生的访问日志必须在产生地所在区域保存至少三十个自然日。在这三十日内，不得把原始访问日志复制到其他地理区域，也不得通过集中排障工具下载完整文件。平台可以跨区同步不含用户标识的聚合指标，例如每分钟请求量和错误率。三十日之后是否继续保留，由当地合规清单决定；本规定没有授权到期自动删除。

访问日志写入前必须遮蔽邮箱、电话号码、精确地址和会话令牌。排障人员需要查看未遮蔽内容时，应提交带有工单编号、目的和有效期的临时访问申请。获批导出的片段仍要留在本区域，工单关闭后删除临时副本。日志存储服务每天检查写入完整性，发现超过十五分钟的缺口需通知当地值班人员。

若某个海外 API 进入弃用流程，原有一百八十日公告要求继续适用；节点日志的三十日驻留要求也继续适用。两项义务彼此独立，完成其中一项不能免除另一项。
