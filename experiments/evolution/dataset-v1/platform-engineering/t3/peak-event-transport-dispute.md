# “星海节”高峰期内部传输配置联合备忘录

文件编号：NS-EVENT-2026-11　起草日期：2026-10-20　拟适用期间：2026-11-10 至 2026-11-12

本备忘录记录尚未解决的部门分歧，不是已经批准的变更。容量与性能委员会根据压力测试认为，星海节峰值期间 mTLS 带来约 7% 的 CPU 开销。该委员会要求订单查询、推荐和库存读取链路在活动期间关闭 mTLS，改用受管网络内的明文 HTTP，并主张活动结束后恢复。委员会认为短期吞吐风险高于传输窃听风险。

安全合规委员会不同意该方案。其意见是，零信任传输升级通知已经明确规定性能压力和营销活动不构成自动例外，交易期间反而应维持 mTLS；如果容量不足，应扩容或降低非核心功能。安全合规委员会要求任何连接降级都必须由安全架构组按单个服务审批，不能由活动级备忘录批量授权。

两个委员会在公司治理结构中级别相同，均无权撤销对方决定，也都不是零信任政策的最终解释机构。截至起草日，安全架构组和技术副总裁没有发布裁决，发布平台也没有收到有效的临时例外清单。容量团队已经准备了关闭开关，安全团队则配置了防止明文流量的策略，两套配置不能同时生效。

因此，本备忘录只能证明存在冲突及各自理由，不能证明活动期间最终应该开启或关闭 mTLS。后续如有正式裁决，应以带编号、生效时间和批准人的文件为准。
