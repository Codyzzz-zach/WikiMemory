# WCAG 2.2 Draft Feedback: Dragging Movements

## Source Snapshot

Success Criterion 2.5.7 Dragging Movements (Level AA): All functionality that uses a dragging movement for operation can be achieved by a single pointer without dragging, unless dragging is essential or the functionality is determined by the user agent and not modified by the author.

We kindly request that the group remove this SC until research is completed for all affected input modalities.

We believe more considerations are needed for various platforms, and that there shouldn’t be an imposition of all mobile requirements on all desktop content.

## Research Notes

- 公开 issue 是提案反馈，不是最终规范结论。
- 最终 WCAG 2.2 保留 2.5.7；这使其适合作为“异议未被最终标准采纳”的测试材料。
